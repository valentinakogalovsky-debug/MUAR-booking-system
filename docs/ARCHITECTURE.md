# MUARÉ — Architecture

Версия: 1.1
Стиль: модульный монолит

## 1. Стек

Next.js App Router, React, TypeScript, Tailwind CSS, PostgreSQL, Prisma, Auth.js, Zod, Vitest и Playwright.

## 2. Поток данных

```text
React Server/Client UI
        ↓
Server Actions / Route Handlers
        ↓
Application services + permissions + validation
        ↓
Prisma transaction
        ↓
PostgreSQL constraints
```

Клиентский код не обращается к БД и не определяет бизнес-значимые поля.

## 3. Модули

- `auth` — сессия ADMIN/STAFF;
- `permissions` — роли, организация, назначенный мастер;
- `catalog` — услуги, дополнения и цены;
- `staff` — профили и компетенции;
- `schedule` — циклы, недели и исключения;
- `availability` — свободные интервалы;
- `booking` — заявки, подтверждение, перенос, отмена;
- `audit` — история и безопасные метаданные;
- `web` — публичный сайт и дизайн-система.

## 4. Границы

Route Handler отвечает за транспорт. Сервис — за правила. Репозиторий/Prisma — за запросы. React-компонент — за представление. Проверки разрешений и доступности нельзя размещать только в UI.

## 5. Критическая операция

Создание заявки:

1. валидировать payload и idempotency key;
2. получить активную услугу, мастера, настройки и график;
3. вычислить `endAt`, `occupiedUntil` и цену;
4. внутри транзакции повторно проверить доступность;
5. upsert клиента по нормализованному телефону;
6. создать `PENDING`, позиции, историю и аудит;
7. преобразовать конфликт ограничения БД в `409`.

## 6. Время

Границы дня строятся в `Europe/Moscow`, затем преобразуются в однозначные instants. В БД используются timestamptz. Нельзя рассчитывать смены через локальный timezone сервера.

## 7. Безопасность

Пароли хешируются; secrets доступны только серверу; вход rate-limited; все изменяющие запросы валидируются и проверяют сессию; приватные списки фильтруются в запросе к БД; аудит исключает пароли и токены.

## 8. Развёртывание

Next.js размещается на Vercel, PostgreSQL — управляемый. Production использует `prisma migrate deploy`; seed не запускается автоматически. До релиза обязательны backup, smoke test и план отката.
