# MUARÉ — Release Notes MVP

Дата release candidate: 12.08.2026

## Что готово

- публичная заявка без регистрации со статусом `PENDING`;
- выбор услуги, даты, времени и свободного мастера;
- запись со страницы выбранного мастера;
- кабинеты администратора и мастера с серверным разграничением прав;
- подтверждение, перенос, отмена, ручная запись и статусы выполнения;
- графики мастеров, исключения и расчёт доступности в `Europe/Moscow`;
- серверная и PostgreSQL-защита от двойного бронирования;
- ограничение частоты публичных заявок, размера запроса и защитные HTTP-заголовки.

## Проверка release candidate

- lint, TypeScript, 39 автоматических тестов и форматирование — успешно;
- production build через Webpack — успешно;
- свежая тестовая PostgreSQL, миграции, seed и параллельная запись в один слот — успешно;
- Prisma validate/generate — успешно;
- `npm audit --omit=dev` — 0 известных уязвимостей;
- Lighthouse: исправлены ошибка favicon, контраст, приоритет и размеры изображений;
- проверены вход администратора и мастера, запрет чужих данных и серверные роли.
