## Пользователи

- `ADMIN` — видит расписание всех мастеров, управляет услугами, графиками и бронированиями.
- `STAFF` — видит только собственное расписание и назначенные записи.
- `CUSTOMER` — видит доступность мастеров и только собственные бронирования.

Вход выполняется по номеру телефона и паролю. Пароль хранится только в виде безопасного хеша.

## Основные правила бронирования

- Старты предлагаются каждые 15 минут.
- После основной услуги блокируется технический перерыв 15 минут.
- Запись подтверждается автоматически при наличии свободного слота.
- Онлайн-запись доступна минимум за 2 часа и максимум на 60 дней вперёд.
- Эти два ограничения изменяются администратором.
- Самостоятельные отмена и перенос разрешены не позднее чем за 8 часов.
- Маникюр и педикюр за один визит выполняются последовательно одним мастером в течение 180 минут.
- Снятие, выравнивание и дизайн могут изменять цену, но не увеличивают длительность основной услуги.
- Сервер повторно проверяет слот перед созданием или переносом.
- Два клиента не могут забронировать одного мастера на пересекающееся время.

## Локальный запуск

```bash
npm install
npm run prisma:generate
npm run dev
```

Откройте `http://localhost:3000`. Полная проверка: `npm run check`.

## Локальная база данных

Проект использует отдельную PostgreSQL-базу `muare_booking_dev`. Создайте локальный
файл `.env` по образцу `.env.example`, затем выполните:

```bash
npm run prisma:validate
npm run prisma:generate
npm run prisma:migrate
npm run prisma:seed
```

Seed можно запускать повторно: он обновляет фиксированные данные MUARÉ и не создаёт
дубликаты. Для визуальной проверки таблиц используйте `npm run prisma:studio`.

В миграции находятся серверные ограничения корректности интервалов, цен и настроек,
а также PostgreSQL exclusion constraint, запрещающий пересекающиеся подтверждённые
брони одного мастера даже при одновременных запросах.

Подробная последовательность находится в [PLAN.md](./PLAN.md).
