Статус: локальный release candidate этапа 12 готов; production-запуск ожидает инфраструктуру.

## О проекте

MUARÉ — многостраничный сайт студии ногтевого сервиса в Брянске со встроенной системой онлайн-записи и защищёнными кабинетами администратора и мастеров.

## Пользователи

- `ADMIN` — видит расписание всех мастеров, управляет услугами, графиками и бронированиями.
- `STAFF` — видит только собственное расписание и назначенные записи.
  Авторизация существует только для администратора и мастеров. Вход выполняется по
  номеру телефона и паролю; пароль хранится только в виде безопасного хеша. Клиент
  оставляет заявку без регистрации.

## Основные правила бронирования

- Старты предлагаются каждые 15 минут.
- После основной услуги блокируется технический перерыв 15 минут.
- Новая заявка получает статус `PENDING` и блокирует выбранный слот.
- После звонка клиенту администратор подтверждает заявку статусом `CONFIRMED`.
- Если связаться с клиентом не удалось, администратор отменяет заявку и освобождает слот.
- Онлайн-запись доступна минимум за 2 часа и максимум на 60 дней вперёд.
- Эти два ограничения изменяются администратором.
- Перенос и отмену выполняет администратор по обращению клиента.
- Маникюр и педикюр за один визит выполняются последовательно одним мастером в течение 180 минут.
- Снятие, выравнивание и дизайн могут изменять цену, но не увеличивают длительность основной услуги.
- Сервер повторно проверяет слот перед созданием заявки или переносом.
- Статусы `PENDING` и `CONFIRMED` одинаково блокируют время мастера.
- Два клиента не могут отправить заявки одному мастеру на пересекающееся время.

## Локальный запуск

```bash
npm install
npm run prisma:generate
npm run dev
```

Откройте `http://localhost:3000`. Полная проверка: `npm run check`.

## Локальная база данных

Проект использует отдельную PostgreSQL-базу `muare_booking_dev`. Создайте локальный
файл `.env` по образцу `.env.example`, затем выполните:

```bash
npm run prisma:validate
npm run prisma:generate
npm run prisma:migrate
npm run prisma:seed
```

Seed можно запускать повторно: он обновляет фиксированные данные MUARÉ и не создаёт
дубликаты. Для визуальной проверки таблиц используйте `npm run prisma:studio`.

В миграции находятся серверные ограничения корректности интервалов, цен и настроек,
а также PostgreSQL exclusion constraint, запрещающий пересекающиеся ожидающие и
подтверждённые записи одного мастера даже при одновременных запросах.

Продуктовые требования находятся в [spec.md](./spec.md), подробная
последовательность — в [PLAN.md](./PLAN.md). При противоречии этих документов
работа останавливается до решения пользователя.
