# Code review

1. Начать с фактического diff и цели задачи.
2. Приоритет: потеря данных, доступ, двойная бронь, неверные время/цена, регрессии.
3. Проверить серверную валидацию и границы ADMIN/STAFF/public.
4. Проверить `PENDING` и `CONFIRMED` как занятые интервалы.
5. Проверить MSK/UTC, транзакции и идемпотентность.
6. Проверить доступность UI и отсутствие лишних клиентских данных.
7. Выдать замечания по критичности с файлами и строками.
8. Если существенных замечаний нет, прямо указать остаточные риски.
