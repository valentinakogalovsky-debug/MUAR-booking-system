# Сначала объяснить

До кода сообщить:

1. Как сейчас работает связанный сценарий.
2. Что именно изменится для пользователя и данных.
3. Какие файлы и модули затрагиваются.
4. Нужны ли миграция, зависимость или изменение контракта.
5. Главные риски и способ проверки.

Если изменение безопасное, локальное и однозначное, после краткого объяснения продолжить работу. Если оно меняет утверждённые бизнес-правила или может потерять данные, дождаться решения пользователя.
