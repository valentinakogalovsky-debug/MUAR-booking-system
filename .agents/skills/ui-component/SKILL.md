# UI-компонент

1. Использовать существующие токены, шрифты и компоненты.
2. Не переписывать страницу ради локальной правки.
3. Сохранять светлую палитру MUARÉ и читаемость текста.
4. Использовать семантическую разметку, видимый focus и доступные подписи.
5. Проверить 360 px, tablet и desktop.
6. Изображения выводить через `next/image` с корректным `sizes` и alt.
7. Не дублировать серверные правила на клиенте.
8. Выполнить lint, typecheck, build и визуальную проверку.
