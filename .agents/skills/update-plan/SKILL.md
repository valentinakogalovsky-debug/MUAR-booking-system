# Обновление плана

1. Сверить выполненное с критериями этапа в `PLAN.md`.
2. Отмечать только подтверждённые проверки и работающие функции.
3. Обновить версию, дату и статус документа.
4. Согласовать маршруты, роли, статусы и бизнес-правила с `README.md`.
5. Не удалять историю решений; спорные изменения фиксировать отдельно.
6. Указать следующий незавершённый этап и его критерии.
