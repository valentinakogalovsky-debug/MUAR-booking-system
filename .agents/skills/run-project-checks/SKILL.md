# Проверки проекта

1. Проверить diff и определить проверки, относящиеся к изменению.
2. Для кодовой задачи выполнить `npm run lint`, `npm run typecheck` и `npm run build`.
3. Для Prisma дополнительно выполнить `npm run prisma:validate` и
   `npm run prisma:generate`; миграцию проверить на отдельной test DB.
4. Запустить релевантные unit, integration и end-to-end тесты, если они существуют.
5. Не использовать `npm audit fix --force`.
6. Не скрывать ошибку, не объявлять проваленную команду успешной и не подменять
   проверку рассуждением.
7. При ошибке определить, относится ли она к задаче; исправить только относящееся.
8. Выдать список команд, результатов и оставшихся рисков.
9. Не разрешать commit или push при критической ошибке.
