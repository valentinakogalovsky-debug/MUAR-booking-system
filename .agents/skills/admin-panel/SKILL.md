# Административная панель

1. Требовать серверную роль `ADMIN` для каждой операции.
2. Показывать очередь `PENDING` отдельно и давать подтвердить после звонка.
3. Подтверждение повторно проверяет состояние записи и не создаёт второй интервал.
4. Отмена требует причины, сохраняет историю и освобождает слот.
5. Ручная запись использует тот же booking service, что публичная заявка.
6. Все списки ограничивать организацией и пагинировать на сервере.
7. Изменения цен, длительности, графиков, статусов и настроек писать в AuditLog.
8. Не позволять UI обходить ограничения БД и серверные permissions.
