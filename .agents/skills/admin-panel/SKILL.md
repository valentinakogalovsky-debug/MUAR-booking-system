# Административная панель

1. Прочитать `spec.md` и этап `PLAN.md`; при конфликте остановиться.
2. Требовать серверную роль `ADMIN` для каждой операции.
3. Реализовать только операции, утверждённые в спецификации.
4. Повторно проверять состояние заявки и доступность на сервере.
5. Использовать единый booking service для публичных и ручных операций.
6. Ограничивать списки организацией и пагинировать на сервере.
7. Журналировать критические изменения без секретов и лишних персональных данных.
8. Не позволять UI обходить ограничения БД и серверные permissions.
