# Создание функции

1. Прочитать `README.md`, `spec.md`, этап `PLAN.md`, связанные документы и код.
2. При конфликте `spec.md` и `PLAN.md` остановиться по правилу `AGENTS.md`.
3. Сформулировать цель, границы, критерии приёмки и затрагиваемые файлы.
4. Проверить влияние на бизнес-правила, архитектуру, API и схему БД.
5. Реализовать минимальный завершённый срез без несвязанного рефакторинга.
6. Не принимать с клиента роль, организацию, цену, длительность, статус или окончание.
7. Добавить тесты пропорционально риску.
8. Использовать `$run-project-checks` перед завершением.
9. Сообщить изменения, проверки, риски и ручной сценарий.
