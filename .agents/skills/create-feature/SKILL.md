# Создание функции

1. Прочитать `README.md`, `PLAN.md`, связанные документы и код.
2. Сформулировать цель, границы, критерии приёмки и затрагиваемые файлы.
3. Проверить, не меняет ли задача бизнес-правила, архитектуру или схему БД.
4. Реализовать минимальный завершённый вертикальный срез.
5. Не принимать с клиента роль, организацию, цену, длительность или окончание записи.
6. Добавить тесты пропорционально риску.
7. Выполнить `npm run lint`, `npm run typecheck` и `npm run build`.
8. Для Prisma дополнительно выполнить validate и generate.
9. Сообщить изменения, проверки, риски и ручной сценарий.
