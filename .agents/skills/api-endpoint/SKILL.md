# API endpoint

1. Сверить контракт с `docs/API_SPECIFICATION.md`.
2. Определить вход, выход, коды ошибок и права доступа.
3. Валидировать вход на сервере; идентичность сотрудника брать из сессии.
4. Для публичной заявки принимать только услугу, мастера, старт и контакты.
5. Цена, длительность, `endAt`, `occupiedUntil` и статус рассчитываются сервером.
6. Использовать идемпотентность для изменяющих операций.
7. Не раскрывать существование приватных данных через 403/404.
8. Добавить тесты успешного сценария, валидации, доступа и конфликта.
