# Доступность записи

1. Прочитать разделы доступности в `spec.md`, этап `PLAN.md`, Data Model и API.
2. При конфликте `spec.md` и `PLAN.md` остановиться.
3. Рассчитывать интервалы на сервере из графиков, исключений и активных записей.
4. Не сохранять заранее созданные свободные слоты.
5. Получать длительность, буфер, настройки и статус из доверенных серверных данных.
6. Сохранять защиту пересечений PostgreSQL и транзакционную повторную проверку.
7. Обрабатывать `Europe/Moscow`, UTC, границы суток и переходы месяцев.
8. Не создавать N+1 запросы для списка мастеров и дня.
9. Добавить тесты свободного, частично занятого и закрытого дня, исключений,
   границы смены, параллельных запросов и разных услуг.
10. Использовать `$run-project-checks` перед завершением.
